# Conn 제품 계약

**공유 화면 하드컷 · v0.7.0 프리뷰.** [English](PRD.md)

Conn은 사람과 에이전트가 같은 터미널 화면을 보고 제어권을 교환하는 앱입니다.
사람이 경로를 고치거나 암호를 입력한 뒤, 같은 셸에서 협업을 이어갑니다.

## 핵심 계약

- 세션은 PTY·프로세스, 화면은 현재 터미널 그리드, 액터는 개별 연결 신원을 담당합니다.
- 공유 여부와 입력 권한을 분리합니다. 공유를 켠 뒤에도 사람에게 제어권이 있습니다.
- 비공유는 영구적인 세션 종류가 아닙니다. 공유 전환은 셸·SSH 연결을 재시작하지 않습니다.
- 코어가 셸 출력을 해석한 현재 화면을 공유합니다. 스크롤백과 원시 입력은 포함하지 않습니다.
- 포커스·최소화·창 가림·다른 탭 선택은 접근 권한을 바꾸지 않습니다. 에이전트는 연결된 셸에 머뭅니다.
- 무표시 암호는 문자가 없고, 별표 암호는 표시된 별표만 전달합니다. 공유 화면에 보이는 비밀값은 참여자에게도 보입니다.
- 사람 입력이 먼저 제어권을 회수합니다. 공유·권한 변경은 충돌하는 대기 작업을 취소합니다.
- 공유 해제·연결 종료·사람 입력은 충돌하는 에이전트 작업을 취소합니다. 단순 창 전환은 취소하지 않습니다.
- 이미 셸에 들어간 입력을 내부 추적기에서만 지우지 않습니다. 다른 액터가 미완성 사람 입력에 덧붙일 수 없습니다.
- 사람의 원시 키·붙여넣기·인증·편집기 입력은 기록하지 않습니다. 지원 셸의 실행 훅만 사람 명령 기록을 만듭니다.
- 제어 허용·명령 승인·제안 수락·실행 동의·실행은 타임라인에서 구별합니다.

## 외부 실행 후 공유

외부 프로그램이 시작한 세션은 자식 실행 전부터 비공유입니다. 소유한 창에서 사람이
공유를 켜고 실제 연결 ID로 참여자를 고릅니다. 기존 외부 입력 권한과 큐는 종료합니다.
시작 명령과 과거 비공유 입력은 소급 기록하지 않습니다. 외부 실행 출처는 유지하며,
이후 에이전트 명령은 명령별 검토를 요구합니다. 로컬 셸에서 SSH·편집기 같은 다른 프로그램을
실행한 경우에도 바깥 셸의 종료 훅을 확인하기 전까지 로컬 파일 기준으로 명령을 허용하지 않습니다.
공유 중단은 이미 전송된 정보를 회수하지 않습니다.

새 에이전트 연결은 사람이 Conn 창에서 한 번 허용할 때까지 대기합니다. 허용은 그 연결에만
적용되며, 설정에서 이 확인을 끌 수 있습니다. 일반 탭은 모드·권한에 따라 허용된 연결이
참여합니다. 제어권은 탭마다 하나인 회수 가능한 임대입니다. 한 번에 한 주체만 쓰고, 사람은
언제든 회수하며, 다른 탭으로 옮긴 에이전트는 쥐고 있던 것을 반납합니다.
[제어권 모델](control-lease-model.ko.md)을 참고하세요. 한 번 참여자를 명시적으로
선택한 뒤에는 같은 이름으로 재접속해도 이전 연결의 허용을 상속하지 않습니다.

## 확장 기능

첫 범위는 선언형 테마, 검토된 내장 모델 제공자, 자동완성 제안입니다. 버전·권한·설정·취소
계약을 공통으로 사용합니다. 임의 제삼자 코드·CSS·DOM·PTY 접근과 마켓플레이스는 제공하지 않습니다.

사용자 API 키는 OS 보안 저장소에 보관합니다. 네이티브 계층이 모델 요청을 중개하고
공유 중인 현재 화면만 문맥으로 제공합니다. 키 저장소가 없으면 평문으로 대체하지 않습니다.
제안을 수락하면 입력만 삽입하며 실행은 별도 Enter입니다. 내장 에이전트도 비공유 화면을 읽지 못합니다.

## 전환과 검증

Entrust 예외, 공개 소켓의 사람/프런트엔드 사칭, 원시 출력 구독, UI 포커스에 의존하는 접근 제한을 제거합니다.
Tauri 앱과 브라우저 테스트는 같은 하네스·UI를 사용합니다. 기본 화면은 간단하게 유지하고
영문·한국어, 팔레트와 공통 모션을 함께 제공합니다.

실제 렌더링, 가림, 숨김/별표 입력, 공유 경쟁 상태, 연결 사칭, 오래된 제안, 인증 후 같은
SSH 연결에서 협업을 검증합니다. Linux 자동 테스트와 macOS·Windows 설치 앱 검증은 구분합니다.
