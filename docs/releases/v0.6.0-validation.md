# v0.6.0 candidate validation

Updated 2026-09-17. This records evidence, not a claim of complete native installation coverage.

## Local checks

- Rust workspace: 198 tests passed, including native PTY, command recording, private automation, audit and frontend harness cases.
- Frontend: 36 tests passed; Svelte type check and production build passed.
- Release tooling: 51 tests passed; exact artifact allowlists, manifest/asset binding, missing/corrupt signatures, notarized-app evidence, and agreement-free DMG mount contract.
- Native updater: channel selection and trusted asset checks; real Tauri updater loopback tests accept a valid public test vector and reject changed bytes, truncated downloads, missing metadata/payloads and offline endpoints. These never install a payload.
- Browser: 10/75/200 real no-op commands retain 24px timeline targets; 720 × 520 layout has no horizontal page overflow. Existing history stays anchored after oldest-record eviction; a new tab starts empty. Numeric pacing shows Custom. Unsaved profile navigation offers discard and does not save the edit. Korean settings and update dialog reviewed.

## Release gates

- Every platform CI job must pass on the exact candidate commit.
- Dedicated updater public key and encrypted signing secrets must be configured before a release build. CI checks actual final payload signatures against the embedded public key.
- macOS Developer ID, hardened runtime, notarization, app/DMG stapling and final contained-app checks remain mandatory.
- Publishing is blocked until the final artifact inventory and signing evidence pass.

## Coverage limits

The prior development-app collaboration session confirmed hidden and masked synthetic password scenarios on macOS. It does not prove every third-party application's behavior or this signed candidate's installer behavior. Installed-app version-to-version upgrades on macOS, Windows and AppImage, permission-denied installation, actual restart and recovery after an install failure still require hands-on testing. Debian-package updates remain manual/package-managed. Intel Mac is excluded.

한국어: 로컬 자동검사와 브라우저 검증을 통과한 범위를 기록했다. 각 OS의 서명된 설치본에서 실제 버전 간 업그레이드·재시작·권한 및 설치 실패 복구까지 검증했다는 의미는 아니다. 릴리스는 최종 CI·서명·산출물 검사를 거쳐야 한다.
