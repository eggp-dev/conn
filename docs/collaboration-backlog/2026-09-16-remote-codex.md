# COLLAB-001 · SSH로 맥북 Codex와 협업

## 목적과 환경

- 날짜: 2026-09-16, KST.
- 목표: Linux Conn에서 Tailscale 장치를 찾고 Mac에 SSH 접속한 뒤, 프로젝트를 준비하고 원격 Codex에 자연어 작업을 요청한다.
- 로컬: Linux 네이티브 Conn 개발 빌드. dev 기반 미커밋 변경(셸 통합 등)이 포함되어 있어 배포판 재현 결과가 아니다. 정확한 빌드 해시는 세션에서 확보하지 않았다.
- 연결: Codex → 지속형 `conn mcp` → 공유 PTY → SSH → macOS zsh → 원격 Codex CLI 0.154.0.
- 정책: Autopilot, 제어 요청 승인 켜짐, 실행 유예 0초, lease 60초.
- 원격: 공개 Conn 저장소 dev 브랜치의 shallow clone. 로컬 미커밋 개발 변경을 전송하지 않았다. macOS 상세 버전은 미확인.
- 성공 기준: 사용자가 보정한 경로에서 원격 Codex의 실제 답변을 받고, 결과 및 파일 변경 여부를 확인한 후 제어권 반환.

## 자연어 요청

> 현재 Conn 저장소의 README.md와 Cargo.toml을 읽고, 이 프로그램의 목적과 사람이 에이전트 작업에 개입하는 방식을 한국어 5줄로 설명해줘. 파일 수정, 설치, 커밋, 네트워크 작업은 하지 마.

원격 Codex는 공유 터미널, MCP/CLI 연결, Rust 구성요소, 사람의 승인과 직접 입력에 따른 제어 반환을 설명했다. 이 답변의 수신은 자연어 실행 검증이며, 제품의 모든 동작을 독립 검증한 것은 아니다.

## 사용자 피드백

직접 인용:

> “니가 폴더를 아무대나 만들려고 해서 내가 보정해주는것.”

> “상당히 흥미로운 협업인것 같은데?”

사용자는 이 사례에서 Conn의 의미를 발견했고, 다른 도구와 비교해서도 협업 느낌이 차별화되는지 질문했다. 비교 제품에 대한 통제된 테스트는 수행하지 않았다.

## 결과와 한계

- 성공: Conn 안에서 장치 발견 → SSH → 사람의 경로 보정 → 원격 Codex 자연어 응답 → 제어 반환.
- 종료: SSH와 지속형 MCP는 유지, 제어권은 사람에게 반환. 프로젝트 작업 트리는 clean.
- 원격 프로젝트는 clone까지만 준비했다. 의존성 전체 설치·앱 빌드·실행은 하지 않았다.
- Bun 쪽 깨진 CLI는 그대로다. npm 경로의 기존 실행 파일을 직접 사용했다.
- 암호 비표시는 해당 화면 관찰에 한정한다. 감사 로그·타임라인·원격 이력의 비밀정보 부재를 이번 세션에서 전수 검사하지 않았다.
- 원격 Codex가 로컬 Conn에 직접 MCP로 연결된 테스트는 아니다. 로컬 에이전트가 SSH 터미널을 통해 원격 CLI를 실행했다.

## 해석과 후속 후보

- **제품 가설:** 사람의 보정을 채팅 설명 대신 같은 작업 공간의 직접 조작으로 전달하면 협업 부담이 줄어든다. 경로 수정 사례 한 건에서 확인한 가능성이다.
- **반증 조건:** 사람이 고친 내용을 에이전트가 놓치거나 되돌리거나, 재개에 더 많은 설명·승인이 필요하면 장점이 줄어든다.
- **버그 후보:** 빈 입력줄 오판과 리사이즈 후 스냅샷 손실. 각각 BUG-C001, BUG-C002로 최소 재현 필요.
- **UX 후보:** 제어 승인과 명령 승인 구분, 연결 상태와 제어 소유 구분. UX-C001, UX-C002.
- **데모 후보:** 경로 제안 → 사람 보정 → 에이전트 재관찰·재개. 실제 개인 환경을 공개하지 말고 재촬영한다(DEMO-C001).
- **다음 검증:** 브랜치·옵션 보정, SSH 연결 단절, 원격 인증/에디터 전환, 타임라인 표현. [누적 백로그](README.md)에서 관리한다.

## 재검증

### 2026-09-16 · 대화형 Codex 재시도

- 깨진 Bun 전역 Codex 0.118.0을 제거했다. 새 로그인 zsh에서 기본 `codex`가 npm 설치 0.154.0으로 실행됨을 확인했다.
- 사용자가 맥북 Codex 대화형 UI를 열었다. 빈 입력창에서 제어권을 받은 후 자연어 조사 요청을 두 번 시도했으나 모두 `input_pending`으로 거절되었다. 요청은 원격 Codex에 전달되지 않았다.
- 사용자가 빈 입력창에서 Enter 후 재시도를 요청했지만 해결되지 않았다. Ctrl-C로 앱을 종료할 가능성이 있어 강제 초기화하지 않았다.
- 로컬 코드 조사: `Term.svelte`는 일반 탭의 terminal-origin 응답도 `input`으로 전달한다. `Session::human_input`은 끝 바이트가 CR/LF/Ctrl-C/Ctrl-U가 아니면 `human_input_pending`을 켜고, `agent_type`은 이 상태에서 입력을 거부한다. 터미널 자동 응답이 입력 중 상태와 제어권 회수를 유발할 가능성이 있다. 실제 트리거 바이트를 수집하지 않았으므로 원인 확정은 아니다.
- BUG-C001에 대화형 앱·터미널 응답 분리 재현을 추가한다. 사용자 요청에 따라 수정은 보류하고 dev 코드 전달·AppleScript 실험으로 전환한다.
