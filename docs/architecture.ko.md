# 아키텍처

**공유 화면 하드컷 · v0.7.0 프리뷰.** [English](architecture.md)

실행·표시·액터·참여·권한·출처·기록을 분리합니다. 코어는 PTY 수명과 입력 권한을
관리하고, 실제 xterm 렌더러가 표시 완료 화면을 제공합니다. Tauri와 인증된 브라우저
테스트 어댑터는 같은 하네스와 UI를 사용합니다.

화면은 ID·공유 세대·프레임 번호·출력 순서로 검증합니다. 공유 변경과 화면 가림은
이전 프레임을 무효화합니다. 스크롤 위치와 숨김 셀도 실제 표시 기준으로 처리하고,
화면이 없으면 별도 VT 버퍼로 대신 응답하지 않습니다. 이미지 생성이 지원되지 않는
렌더러에서는 그 상태를 명시합니다. 화면 부재는 관찰·실행을 멈추고 자동완성을 취소하며,
대기 중인 사람 승인·제어 결정은 새 프레임이 확인된 뒤 이어갈 수 있습니다.

공개 IPC는 에이전트 전용입니다. 화면 게시·공유 변경·사람 승인 API는 어댑터가 확인한
소유 창에서만 호출합니다. 같은 표시 이름으로 재접속해도 연결 권한은 상속되지 않습니다.
외부 실행 출처는 공유 여부와 분리하고, 공유 전의 시작 명령·입력·출력을 소급 기록하지 않습니다.

확장 호스트는 버전과 권한이 있는 선언형 등록 정보를 사용합니다. 첫 범위는 테마,
내장 모델 제공자와 제안입니다. 임의 코드·PTY·DOM·전체 이벤트 접근은 개방하지 않습니다.
모델 요청은 OS 키 저장소와 네이티브 중개 계층을 사용합니다. 공유된 현재 화면을 받을 때
취소 작업도 함께 등록하고, 응답과 수락 시 프레임 유효성을 다시 확인합니다. 수락은
공통 사람 입력 경로를 사용하며 Enter를 보내지 않습니다.
