## 같은 셸에서 방향 바꾸기

1. **Codex가 시작 위치를 확인합니다.** 외부 클라이언트가 Conn에 제어를 요청하고, `draft`에서 `pwd`를 실행한 뒤 기다립니다.
2. **사람 역할이 경로를 바꿉니다.** Conn에 직접 입력하면 제어권을 되찾습니다. `cd ../workspace`와 `pwd`로 작업할 위치를 지정합니다.
3. **Codex가 바뀐 상태를 읽습니다.** “경로를 바꿨어. 터미널을 읽고 여기서 계속해.”라고 요청합니다. 새 화면을 확인한 다음 제어 요청과 명령 승인을 거칩니다.
4. **그 자리에서 작업을 이어갑니다.** Codex가 `workspace/collaboration.txt`를 만들고 읽습니다. `draft/collaboration.txt`는 없다는 것도 확인한 뒤 제어를 반환합니다.

파일에는 `We continued from your correction.` 한 줄과 줄바꿈이 들어갑니다. 별도의 바이트 검사로 내용이 정확한지, 원래 경로에 파일이 없는지도 확인했습니다.

## 실제 촬영 범위

2026년 9월 17일 Ubuntu에서 **Codex CLI 0.153.0**, **gpt-6-astra**, medium 추론 설정과 Conn의 네이티브 Rust 백엔드를 사용했습니다. 실제 Svelte UI를 브라우저 테스트 어댑터로 열었으며, 촬영한 앱 코드는 v0.6.0과 같습니다. 좌우 분할 화면은 촬영 도구이며 별도의 Conn 제품 화면이 아닙니다.

이 영상은 실제로 경험한 협업을 준비된 환경에서 재현한 것입니다. 촬영 도구가 과제를 전달하고 사람 역할의 승인, 경로 변경, 후속 요청을 수행합니다. **독립적인 사람이 참여한 사용자 테스트는 아닙니다.** Codex는 명령을 직접 선택해 Conn의 MCP 서버로 실행합니다. 터미널 출력과 앱의 반응은 실제 동작입니다.

촬영용 지침에는 기다릴 시점과 이후 파일 하나를 만드는 과제가 미리 들어 있습니다. 화면의 짧은 후속 요청은 이 지침을 전제로 합니다. [첫 협업 가이드](first-collaboration.ko.md)에는 새 세션에서 사용할 수 있는 완전한 요청문을 제공합니다. 이번 촬영에서는 Codex가 Python 3로 기존 파일을 덮어쓰지 않는 생성 명령을 선택했습니다. 가이드가 같은 명령을 강제하지는 않습니다.

## 편집 방식

- 화면을 고정하고 줌과 팬을 사용하지 않았습니다. 제목과 자막은 두 터미널 바깥에 배치했습니다.
- 도입부는 실제 경로 변경을 먼저 보여주고 **“그 직전”**으로 돌아갑니다. 이후에는 대기 시간을 줄이되 사건 순서를 유지합니다.
- 제어 허용과 명령 정책 승인은 실제로 따로 진행됩니다. 긴 영상에는 제어 재요청과 파일 생성 승인이 나오며, 짧은 영상은 경로 변경에서 확인된 결과로 넘어갑니다.
- 두 언어판은 같은 촬영본을 사용합니다. [촬영 기록](../media/demo/RECORDING-HANDOFF.md)과 [편집 명세](../media/demo/HANDOFF.md)에 선택 구간과 검증 범위를 남겼습니다.

저장소의 포스터는 영상 파일로 연결됩니다. GitHub 인라인 재생은 공개 시 검수한 영상을 첨부하고 실제 발급된 URL을 넣어야 합니다. 저장소 MP4 링크만으로 인라인 플레이어가 생기지는 않습니다.

## 결과를 읽는 기준

직접 입력하면 제어권을 가져와 이후 에이전트 입력을 막습니다. 이미 실행 중인 프로세스를 종료하지는 않습니다. 이 시나리오에서는 에이전트가 경로 변경 전에 기다리고, 계속하라는 요청을 받은 뒤 화면을 다시 읽습니다.

타임라인은 명령과 협업 결정을 기록합니다. 터미널 출력이나 스크롤백을 보관하지 않으며, 셸에 전달됐다는 기록만으로 성공을 판단할 수는 없습니다. 이번에는 실제 셸 출력과 별도의 파일 검사로 결과를 확인했습니다.

촬영으로 확인한 범위는 영상에 나온 Ubuntu 로컬 흐름입니다. 모든 클라이언트·네이티브 설치 파일·원격 작업을 검증한 것은 아닙니다. 원래 원격 실험에서는 해결하지 못한 대화형 `input_pending` 문제도 있었고, [사례 기록](collaboration-story.ko.md)에 성공한 제어 전환과 구분해 남겼습니다.
