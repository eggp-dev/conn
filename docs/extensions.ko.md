# 확장 기능

[English](extensions.md) · [신뢰 모델](security.md#native-extensions-and-model-data)

**미배포 하드컷 기능입니다.** 작업 트리에 터미널 테마, 내장 OpenAI 연결과 선택적으로 켜는
명령 제안을 추가합니다. v0.6.0 배포본에는 없습니다. 마켓플레이스나 임의의 제삼자
실행 코드를 설치하는 기능은 제공하지 않습니다.

## 터미널 테마 바꾸기

**설정 → 확장**에서 Midnight·Paper·Solar·Nord·Mono를 고르거나 **테마 설치…**로
Conn 테마 JSON을 가져옵니다. 테마는 지원되는 터미널 색상만 바꿉니다. 승인 컨트롤을
숨기거나 공유를 바꾸거나 스크립트·명령을 실행하거나 앱 내비게이션을 대체할 수 없습니다.
기존 외형 설정은 별도로 유지합니다.

테마 파일의 전체 예제는 [영문 문서](extensions.md#change-a-terminal-theme)에 있습니다.

- `apiVersion: 1`, `kind: "theme"`, `capabilities: ["theme"]`를 사용합니다.
- `id`는 고유해야 하며 테마 내부의 `id`와 일치해야 합니다.
- 배경·글자·커서·선택 영역은 여섯 자리 16진수 색상입니다.
- `ansi`는 기본 여덟 색과 밝은 여덟 색을 순서대로 포함합니다.
- 알 수 없는 필드·API 버전·중복 ID·추가 권한·실행 진입점은 거절합니다.
- 사용자 테마는 최대 32개이며 `extensions.json`에 저장합니다.

첫 확장 호스트는 셸 시작 파일을 편집하거나 프롬프트 프로그램을 설치하지 않습니다.
실제 셸 코드를 실행하는 프롬프트 확장은 별도의 실행 계약이 필요합니다.

## 내 OpenAI 계정 연결하기

1. **설정 → 확장**에서 내 API 계정에 허용된 모델 ID를 입력하고 저장합니다.
2. API 키를 입력하고 **키 저장**을 누릅니다. 제출 후 입력칸을 비우며 저장된 원문을
   웹뷰로 다시 가져오는 API는 없습니다.
3. **OpenAI**와 **명령 제안**을 켭니다. 확인된 로컬 셸 프롬프트에서는 입력을
   잠시 멈추면 모델 요청이 발생합니다.
4. 현재 공유 중이고 화면에 보이는 터미널로 돌아가 명령을 이어 쓸 위치에 커서를 둡니다.
5. 지원하는 로컬 프롬프트에서 입력을 멈추거나 명령 팔레트의 **명령 제안**을
   선택합니다. 결과를 검토한 뒤 **입력**을 누르고, 실행하려면 터미널에서 별도로
   Enter를 누릅니다.

API 계정은 외부 에이전트 클라이언트의 로그인·구독과 별개입니다. Conn은 Codex/ChatGPT
인증정보를 가져오거나 셸 환경의 `OPENAI_API_KEY`를 읽지 않습니다. 자신의 API 키를
사용하며 모델 접근과 요금은 해당 계정에 따릅니다.

기능을 켜면 입력을 800ms 동안 멈춘 뒤 네이티브 호스트가 확인한 로컬 셸 프롬프트에서
자동으로 요청합니다. 사람에게 제어권이 있어야 하며 실행 중인 명령이 없어야 합니다.
호출 신호에는 입력 문자가 없고 모델 문맥은 현재 표시 프레임에서만 만듭니다. 인증창·
편집기·실행 중 명령·외부 실행 세션·확인되지 않은 셸에서는 자동 요청하지 않습니다.
확인되지 않은 환경에서는 명령 팔레트로 직접 요청할 수 있으므로 사용자가 명령 입력
상황인지 확인해야 합니다. **명령 제안**을 끄면 자동·수동 요청을 모두 중단합니다.

제안은 현재 입력 뒤에 붙이는 텍스트이며 전체 명령 대체나 자동 실행이 아닙니다.
화면·입력·공유 상태·설정이 바뀌거나 취소하면 무효화합니다. 터미널을 보정했다면 새로
요청하세요. 오래된 제안을 다른 세션·화면·프레임에 적용할 수 없습니다.

## 전송·저장 범위

허용된 현재 화면의 텍스트만 고정된 OpenAI HTTPS 주소로 전송합니다. 숨겨진 입력 버퍼,
파일·히스토리·환경·시작 인자·이전 모델 대화는 추가하지 않습니다. 공유 화면에 이미 보이는
정보에는 민감한 값이 포함될 수 있으며 비밀정보 탐지 기능은 아닙니다. 비공유 상태에서는
명령 제안을 요청할 수 없습니다.

키는 macOS Keychain, Windows Credential Manager, Linux Secret Service를 사용합니다.
보안 저장소가 잠겼거나 없으면 오류를 반환하고 평문 저장으로 대체하지 않습니다. 네이티브
백엔드만 저장 상태 확인과 검토된 모델 요청을 위해 키를 읽습니다. 확장 JSON·셸 환경·
타임라인·제안 데이터에는 저장하지 않습니다. 키를 지우면 대기 제안도 취소합니다. 삭제 오류는 OS 저장소에서 삭제를
확인하지 못했다는 뜻입니다.

연결 제한은 5초, 전체 요청은 20초입니다. 문맥은 16 KiB, 응답은 64 KiB, 제안은 1 KiB
이하이며 제안은 30초 후 만료됩니다. 앱당 동시 작업은 2개, 분당 시작은 20회입니다.
자동 재시도·도구 호출·리디렉션·환경 프록시 변경은 사용하지 않습니다. `store: false`를
보내지만 제공자의 보관이 전혀 없다는 보장은 아닙니다. 로컬 취소로 제공자가 이미 시작한
처리나 과금까지 취소한다고 보장하지 않습니다.

## 확장 구조

| 기여 기능 | 권한 | 실행 방식 |
| --- | --- | --- |
| 터미널 테마 | `theme` | 검증된 선언형 색상 |
| 내장 OpenAI 제공자 | `model_request` | 검토된 네이티브 HTTPS 어댑터 |
| 내장 명령 제안 | `visible_frame`, `model_request`, `proposal` | 호스트가 허용한 화면과 인간의 수락 |

등록·설정·권한·취소·결과 만료·공통 UI는 Conn이 소유합니다. 확장은 PTY나 소유자 브리지를
받지 않습니다. 모델 제공자와 제안 처리를 분리해 다른 검토된 제공자도 같은 제안 흐름을
재사용할 수 있습니다. manifest 자체가 실행 코드를 격리하는 것은 아닙니다. 임의의
네이티브·JavaScript 실행, 자유로운 네트워크·파일 접근, 웹뷰, 플러그인 간 의존성은
첫 호스트의 범위에서 제외합니다.

구현 계약은 [`crates/frontend/src/extensions`](../crates/frontend/src/extensions/README.md)에
있습니다. 기존 `plugin/` 디렉터리는 **외부 클라이언트용 MCP·스킬 연결 패키지**이며
새로운 앱 내부 확장 런타임과 구분합니다.

## 검증 범위

단위 테스트는 가짜 모델 제공자와 메모리 보안 저장소를 사용합니다. 비공유 문맥 차단,
키 읽기를 기다리는 중 취소, 오래된 제안·재수락, 설정 변경, 크기 제한, 스키마 거절과
설정 직렬화의 키 제외를 검사합니다. 유료 요청이나 실제 키체인 변경을 수행하지 않으며
macOS·Windows의 잠금 해제·화면 동작을 증명하지 않습니다.

배포 전 각 OS에서 사용자가 설정한 모델과 실제 보안 저장소를 별도로 확인해야 합니다.
요청 형식은 [OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/text), 공유 데이터
범위는 [신뢰 모델](security.md)을 참고하세요.
